Input and output ​

Simulation output is handled by package extensions, so these functions only exist once the corresponding package is loaded.

  • ParaView (using WriteVTK): vtkWriter opens a .pvd collection and save! appends the current state as a time step, giving a file ParaView can animate. Which fields are written is controlled by the attrib dictionary (see default_attrib). using ReadVTK adds the matching load!, for restarting from a written collection.

  • Checkpoints (using JLD2): save! and load! on a Flow or a MeanFlow write and read the raw arrays, which is the cheaper way to restart a run that you do not need to visualise.

ParaView output ​

WaterLilyWriteVTKExt.VTKWriter Type
julia
VTKWriter(fname;attrib,dir,T)

Generates a VTKWriter that hold the collection name to which the vtk files are written. The default attributes that are saved are the Velocity and the Pressure fields. Custom attributes can be passed as Dict{String,Function} to the attrib keyword.

source
Base.close Method
julia
close(w::VTKWriter)

Closes the VTKWriter, this is required to write the collection file.

source
WaterLily.default_attrib Method
julia
default_attrib()

Returns a Dict containing the name and bound_function for the default attributes. The name is used as the key in the vtk file and the bound_function generates the data to put in the file. With this approach, any variable can be save to the vtk file.

Restarting from ParaView output ​

WaterLily.load! Method
julia
load!(a::AbstractSimulation, ::Val{:pvd}; kwargs...)

Restart a simulation from a pvd collection file, using the last saved vtk file. The velocity and pressure field of a::AbstractSimulation``are overwriten by the one in the vtk file. The time step is also updated to match the time step of the vtk file, such that the simulation can be restarted and continued. Keyword arguments considered arefname="WaterLily.pvd"andattrib=default_attrib()`.

source

components_last(a::Array)

Permute the dimensions such that the u₁,u₂,(u₃) components of a vector field are the last dimensions and not the first this is reqired for the vtk file.

JLD2 checkpoints ​

WaterLily.load! Method
julia
load!(flow::AbstractFlow; fname="WaterLily.jld2", dir="./", scale=1)

Load pressure, velocity, and time steps arrays from a JLD2-formatted binary file, interpolated onto flow's grid when its resolution is scale times the stored one or its domain is larger.

source
WaterLily.load! Method
julia
load!(meanflow::MeanFlow; fname="WaterLilyMean.jld2", dir="./", scale=1)

Load time-averaged pressure, velocity, velocity-square, and time arrays from a JLD2-formatted binary file, interpolated as in load!(flow::AbstractFlow).
