# Code gallery

!!! info "Coming soon"
    The code gallery, programs that show what WaterLily can do in combination with the rest of
    its [ecosystem](../ecosystem.md), is being prepared and will be added to these pages soon.

In the meantime, the [WaterLily-Examples](https://github.com/WaterLily-jl/WaterLily-Examples)
repository holds a large collection of example programs, including ones that need packages
WaterLily itself does not depend on, such as parametric bodies, Biot-Savart boundary conditions
and optimisation.

!!! note "Contribute to the gallery!"
    Most of the gallery will be user contributed. If you use WaterLily and have something you want
    to share, such as the solver for a published paper, a coupling to another code, or just a nice
    trick, please get in touch by [raising an issue](https://github.com/WaterLily-jl/WaterLily.jl/issues/new/choose).
